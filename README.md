# Street Clash

A browser-only 3D Canvas fighting game powered by a local copy of Three.js. Open `index.html` directly in a browser to play.

Controls:
- A/D: move
- W: jump
- Q/E: move in 3D depth
- S: guard
- J: light attack
- K: heavy attack
- L: special / super when meter is full
- Escape: pause
